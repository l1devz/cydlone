Cydlone Geliştirici Belgeleri

Cydlone için bot yaz

Botlar sunucularda mesajlara cevap veren, komut çalıştıran ve topluluğa yardım eden hesaplardır. Discord bot yazdıysan kendini evinde hissedeceksin: bir uygulama oluşturursun, botunun token'ını alırsın, botu sunucuna davet edersin ve birkaç satır Python ya da Node.js koduyla çalıştırırsın.

Hızlı başlangıç5 dakikada ilk botunu çalıştır Canlı olaylarMesajları anında dinle REST APIMesaj gönder, düzenle, sil

Hızlı başlangıç

  1. Uygulama oluştur

    Cydlone'da Ayarlar → Uygulamalar sayfasına git ve Yeni Uygulama'ya bas. Uygulamaya bir ad ver; aynı adla bir bot hesabı da oluşturulur.

  2. Token'ı kaydet

    Oluşturunca botunun token'ı gösterilir. Bu, botunun şifresidir ve sadece bir kez görünür. Kopyalayıp güvenli bir yere kaydet. Kaybedersen uygulama sayfasından Token'ı Sıfırla ile yenisini alırsın.

    Token'ı kimseyle paylaşma. Token'ı bilen herkes botun adına mesaj atabilir. Kodunu GitHub'a koyarken token'ı koda yazma; ortam değişkeninden oku.

  3. Botu sunucuna davet et

    Uygulama sayfasındaki Botu Sunucuya Ekle bölümünde botunun ihtiyaç duyduğu izinleri seç ve bağlantıyı aç. Açılan sayfada "Sunucuyu Yönet" izni olduğun bir sunucu seçip Yetkilendir'e bas. Bağlantı şöyle görünür:

    http://localhost:3000/oauth2/authorize?client_id=UYGULAMA_KIMLIGI&permissions=VIEW_CHANNEL,SEND_MESSAGES

  4. Kodu çalıştır

    Aşağıdaki örneklerden birini kopyala, token'ını ortam değişkenine koy ve çalıştır. Bot çevrimiçi olur ve !ping yazana Pong! 🏓 diye cevap verir.

İlk botun: !ping → Pong!

Botlar iki şeyi birlikte kullanır: canlı olaylar (Socket.io) ile mesajları dinler, REST API ile cevap gönderir. İki örnek de aynı şeyi yapar; hangi dili seviyorsan onu seç.

1. Kur (Node.js 18 veya üstü)

mkdir cydlone-bot
cd cydlone-bot
npm init -y
npm install socket.io-client

2. bot.js dosyasını oluştur

// Cydlone örnek botu: "!ping" yazana "Pong!" der.
const { io } = require('socket.io-client');

const TOKEN = process.env.CYDLONE_TOKEN;                    // Ayarlar → Uygulamalar'daki bot token'ı
const BASE_URL = process.env.CYDLONE_URL || 'http://localhost:3000';

if (!TOKEN) {
  console.error('CYDLONE_TOKEN ortam değişkeni eksik.');
  process.exit(1);
}

// REST isteği: her istekte "Authorization: Bot <token>" başlığı gönderilir.
async function api(method, path, body) {
  const res = await fetch(BASE_URL + path, {
    method,
    headers: { Authorization: `Bot ${TOKEN}`, ...(body ? { 'Content-Type': 'application/json' } : {}) },
    body: body ? JSON.stringify(body) : undefined,
  });
  const data = await res.json().catch(() => ({}));
  if (!res.ok) throw new Error(data.error || `HTTP ${res.status}`);
  return data;
}

// Canlı olaylar: Socket.io bağlantısı, token "auth" içinde gönderilir.
const socket = io(BASE_URL, { auth: { token: `Bot ${TOKEN}` } });
let me = null;

socket.on('ready', ({ user, servers }) => {
  me = user;
  console.log(`${user.username}#${user.discriminator} olarak bağlandı (${servers.length} sunucu).`);
});

socket.on('message:new', async ({ message }) => {
  // Kendi mesajlarına ve başka botlara cevap verme (sonsuz döngü olmasın).
  if (message.authorId === me?.id || message.author?.bot) return;

  if (message.content.trim() === '!ping') {
    await api('POST', `/api/channels/${message.channelId}/messages`, {
      content: 'Pong! 🏓',
      replyTo: message.id, // mesaja yanıt olarak gönder
    });
  }
});

socket.on('connect_error', (err) => console.error('Bağlanamadı:', err.message));
socket.on('disconnect', (reason) => console.log('Bağlantı koptu:', reason));

3. Çalıştır

$env:CYDLONE_TOKEN = "BURAYA_TOKEN"
node bot.js

# macOS / Linux
CYDLONE_TOKEN="BURAYA_TOKEN" node bot.js

1. Kur (Python 3.9 veya üstü)

pip install "python-socketio[client]" requests

2. bot.py dosyasını oluştur

# Cydlone örnek botu: "!ping" yazana "Pong!" der.
import os
import sys

import requests
import socketio

TOKEN = os.environ.get("CYDLONE_TOKEN")                       # Ayarlar → Uygulamalar'daki bot token'ı
BASE_URL = os.environ.get("CYDLONE_URL", "http://localhost:3000")

if not TOKEN:
    sys.exit("CYDLONE_TOKEN ortam değişkeni eksik.")

HEADERS = {"Authorization": f"Bot {TOKEN}"}


def api(method, path, body=None):
    """REST isteği: her istekte "Authorization: Bot <token>" başlığı gönderilir."""
    res = requests.request(method, BASE_URL + path, headers=HEADERS, json=body, timeout=10)
    data = res.json() if res.content else {}
    if not res.ok:
        raise RuntimeError(data.get("error", f"HTTP {res.status_code}"))
    return data


sio = socketio.Client()
me = {}


@sio.on("ready")
def on_ready(data):
    me.update(data["user"])
    print(f'{me["username"]}#{me["discriminator"]} olarak bağlandı ({len(data["servers"])} sunucu).')


@sio.on("message:new")
def on_message(data):
    message = data["message"]
    # Kendi mesajlarına ve başka botlara cevap verme (sonsuz döngü olmasın).
    if message["authorId"] == me.get("id") or (message.get("author") or {}).get("bot"):
        return

    if message["content"].strip() == "!ping":
        api("POST", f'/api/channels/{message["channelId"]}/messages', {
            "content": "Pong! 🏓",
            "replyTo": message["id"],  # mesaja yanıt olarak gönder
        })


@sio.event
def disconnect():
    print("Bağlantı koptu.")


# Canlı olaylar: Socket.io bağlantısı, token "auth" içinde gönderilir.
sio.connect(BASE_URL, auth={"token": f"Bot {TOKEN}"})
sio.wait()

Eğik çizgi komutları

Kullanıcılar mesaj kutusuna / yazınca sunucudaki botların komutlarını görür, birini seçince seçenekleri (rol, üye, kanal, sayı, yazı...) bir formdan doldurur. Komut gönderilince bot interaction:create olayını alır ve yanıt verir.

1. Komutları kaydet

Bot bağlandığında komut listesini PUT /api/applications/@me/commands ile gönderir. Liste botun bütün komutlarının yerine geçer; her başlangıçta göndermek güvenlidir.

AlanAçıklama
name1-32 karakter; küçük harf, rakam, - ve _
description1-100 karakter; listede görünür
optionsEn fazla 25 seçenek: { name, description, type, required }. Zorunlular önce gelir.
typestring · integer · number · boolean · user · role · channel
default_member_permissionsİsteğe bağlı izin listesi, ör. ["MANAGE_ROLES"]. Bu izinleri olmayanlar komutu göremez ve kullanamaz.

2. Komutu karşıla

# Eğik çizgi komutu: /zar yuz:20 -> embed ile sonuç, sadece kullanana görünür
import random

COMMANDS = [
    {
        "name": "zar",
        "description": "Zar atar",
        "options": [
            {"name": "yuz", "description": "Zarın yüz sayısı (varsayılan 6)", "type": "integer", "required": False},
        ],
    },
]


@sio.on("ready")
def on_ready(data):
    me.update(data["user"])
    api("PUT", "/api/applications/@me/commands", COMMANDS)  # komutları kaydet


@sio.on("interaction:create")
def on_interaction(interaction):
    if interaction["command"]["name"] != "zar":
        return
    options = {o["name"]: o["value"] for o in interaction["options"]}
    sides = options.get("yuz", 6)
    api("POST", f'/api/interactions/{interaction["id"]}/callback', {
        "type": "reply",
        "data": {
            "ephemeral": True,  # sadece komutu kullanan görür
            "embeds": [{
                "title": "🎲 Zar atıldı",
                "description": f"{random.randint(1, sides)} geldi (1-{sides})",
                "color": "#8b5cf6",
            }],
        },
    })
// Eğik çizgi komutu: /zar yuz:20 -> embed ile sonuç, sadece kullanana görünür
const COMMANDS = [
  {
    name: 'zar',
    description: 'Zar atar',
    options: [
      { name: 'yuz', description: 'Zarın yüz sayısı (varsayılan 6)', type: 'integer', required: false },
    ],
  },
];

socket.on('ready', async ({ user }) => {
  me = user;
  await api('PUT', '/api/applications/@me/commands', COMMANDS); // komutları kaydet

socket.on('interaction:create', async (interaction) => {
  if (interaction.command.name !== 'zar') return;
  const options = Object.fromEntries(interaction.options.map((o) => [o.name, o.value]));
  const sides = options.yuz ?? 6;
  await api('POST', `/api/interactions/${interaction.id}/callback`, {
    type: 'reply',
    data: {
      ephemeral: true, // sadece komutu kullanan görür
      embeds: [{
        title: '🎲 Zar atıldı',

        color: '#8b5cf6',
      }],
    },
  });
});

Yanıt ve "düşünüyor..."

Bot her komuta 3 saniye içinde POST /api/interactions/:id/callback ile yanıt vermelidir. Vermezse kullanıcı "Uygulama yanıt vermedi." görür.

typeNe olur
replyYanıt hemen gönderilir: { "type": "reply", "data": { "content", "embeds", "ephemeral" } }
deferKanalda "<bot> düşünüyor..." görünür. Bot işini bitirince PATCH /api/interactions/:id/original ile bu mesajı doldurur (15 dakika süre).

"ephemeral": true verilirse yanıt sadece komutu kullanan kişiye görünür ("Sadece sen görebilirsin" notuyla) ve kaydedilmez; sayfa yenilenince kaybolur. Hata mesajları ve kişisel bilgiler için idealdir. Ertelenen yanıtta ephemeral'ı defer ile birlikte ver.

Uzun süren işler için örnek:

@sio.on("interaction:create")
def on_interaction(interaction):
    if interaction["command"]["name"] == "rapor":
        # 1) 3 saniye içinde "defer": kanalda "<bot> düşünüyor..." görünür
        api("POST", f'/api/interactions/{interaction["id"]}/callback', {"type": "defer"})
        # 2) Uzun işi arka planda yap (olay döngüsünü bekletme)
        sio.start_background_task(rapor_hazirla, interaction)


def rapor_hazirla(interaction):
    sonuc = uzun_suren_is()
    # 3) "düşünüyor..." mesajını sonuçla değiştir (15 dakika içinde)
    api("PATCH", f'/api/interactions/{interaction["id"]}/original', {"content": f"Rapor hazır: {sonuc}"})

İlk yanıttan sonra ek mesaj göndermek için POST /api/interactions/:id/followup ({ content, embeds, ephemeral }) kullan. Bir etkileşime sadece bir kez callback verilebilir.

Kimlik doğrulama

Bot, kendini token'ıyla tanıtır. Token'ın başına Bot yazılır.

NeredeNasıl
REST APIHer istekte Authorization: Bot <token> başlığı
Canlı olaylario(URL, { auth: { token: 'Bot <token>' } })

Token geçersizse REST 401 döner, Socket.io bağlantısı unauthorized hatasıyla reddedilir. Token sıfırlanınca bağlı bot hemen düşer.

Canlı olaylar

Bağlantı kurulunca bot, üyesi olduğu sunucuların olaylarını alır. Bir kanalın olaylarını almak için botun o kanalı görme izni olmalıdır.

Bot kendi gönderdiği mesajın message:new olayını da alır. Örneklerdeki gibi message.authorId === me.id kontrolüyle kendi mesajlarını atla.

Tüm adresler Cydlone'un adresine göredir (ör. http://localhost:3000). Gövde gönderirken Content-Type: application/json kullan. Hatalarda gövde { "error": "açıklama" } biçimindedir.

  -H "Content-Type: application/json" \

İzinler

Moderasyon

Botlar, rollerindeki izinler yettiği sürece üyeleri atabilir, yasaklayabilir ve rollerini değiştirebilir. Rol hiyerarşisi Discord'daki gibidir:

  • Rol verip almak için "Rolleri Yönet" izni gerekir; bot sadece kendi en yüksek rolünün altındaki rolleri verebilir. Rolü kime verdiği önemli değildir (sunucu sahibine bile verilebilir).
  • Atmak ve yasaklamak için hedefin en yüksek rolü botunkinden düşük olmalıdır. Sunucu sahibi atılamaz ve yasaklanamaz.
  • Yasaklanan kullanıcı davet bağlantısıyla tekrar katılamaz; yasaklanan bot da davet sayfasından eklenemez.

Yasaklarken deleteMessages ile kişinin son mesajları silinebilir: 0 (silme), 1 (son 1 saat), 24 (son 24 saat) ya da 168 (son 7 gün).

# Python: bir üyeyi sebep belirterek yasakla ve son 24 saatin mesajlarını sil
api("POST", f"/api/servers/{server_id}/bans/{user_id}", {
    "reason": "Reklam",
    "deleteMessages": 24,
})

Sınırlar ve ipuçları

  • Bir hesap en fazla 10 uygulama oluşturabilir.
  • Botlar arkadaş ekleyemez, sunucu oluşturamaz ve davet koduyla sunucuya katılamaz; sunucuya sadece davet bağlantısıyla eklenir.
  • Botlar şifreyle giriş yapamaz; tek kimliği token'ıdır.
  • Bot sadece görebildiği kanalların olaylarını alır ve izni olduğu işlemleri yapabilir; izinler sunucudaki rollerden gelir.
  • Her mesaja cevap verme; sadece komutlara (ör. ! ile başlayanlara) tepki ver ve başka botları yok say.
  • Bağlantı ağ yüzünden koparsa Socket.io kendiliğinden yeniden bağlanır ve ready olayı yeniden gelir. Token sıfırlanırsa bağlantıyı sunucu kapatır; bot yeni tokenla yeniden başlatılana kadar bağlanmaz.
